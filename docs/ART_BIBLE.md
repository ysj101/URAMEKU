# ウラメク — C-2 アートディレクション / デザイン正本

## 正本

`design/reference/c2-canonical-board.png` に含まれるC-2「新聞・雑誌コラージュ」を世界観の正本とする。公開用仕様書に他社作品の名前・URLを記さない。

## 基本原則

- 新聞の切り抜き、黒い印刷、赤と青の差し色、擦れた紙。立体的な影・3D化をしない。
- 文章の可読性を最優先。複雑な新聞文字の貼り込みを情報の本体として使用しない。
- キャラの再解釈を禁止。髪、眼鏡、猫の耳、部長の帽子は既存マスターに固定。
- シノブ：鋭い黒髪の紙型、赤い書類と赤いアクセント。メガ：角張った髪、丸眼鏡。クロ：黒い猫のシルエット。ハラダ部長：帽子、口ひげ。
- ゲーム本文と数値は必ずHTMLの読み取り可能なテキストで表示。事件資料PNGは「縮小サムネイル」であり、読ませる証拠そのものではない。

## 色

`#242322` インク / `#F5F0E6` 紙 / `#FFF9EF` 白紙 / `#D44843` 赤 / `#437A92` 青 / `#E4D8C2` 古紙 / `#86817A` 補助。

## コミット前のアートQA

1. 正本との並列表示：シルエット・顔・衣装を確認。
2. 透明部分のフリンジ・印刷の質感・書類への重なり順を確認。
3. 100%および200%表示と、スマホ実表示で破綻の有無を確認。
4. 背景ノイズに埋もれない情報コントラストを確保。
5. 擬似的な表情バッジは「リアクション」であって、表情差分の正式原画とは呼ばない。

## 現行パックの品質注記

キャラクターの顔を再生成しない `reactions/` には、元の原画と演出用記号を合成した画像が含まれる。今後の表情作画とは区別する。`src/data/assets.ts` の `characterPose()` と `src/components/CharImage.tsx` は存在するポーズ以外を指定した場合に型エラー・実行時例外になる（使える組み合わせは `docs/CHARACTER_USAGE.md`）。本番承認は人の目と実端末で行う。
