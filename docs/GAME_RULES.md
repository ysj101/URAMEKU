# ウラメク V2 — ゲームルール

現行ルールはV2。旧採点の履歴は `archive/game-v1/GAME_RULES.md`。ゲームの版と保存形式の版は独立する。

## 調査

資料の開封にJSON指定のコストを使う。再読は無料、予算超過・未読資料の採用は禁止。無料資料も明示的に開いて読む。調査順を選び、根拠として採用する。予算切れは非難せず再挑戦で回復する。

## 情報解読と根拠

主張を裏付けられる、資料と矛盾する、確認できない、という区分を資料に基づき読む。解読タスクは選択だけでは足りず、採用した根拠資料が必要。別の妥当な解釈はJSONに複数定義できる。資料間の関係は補強・反証・条件・時系列をラベルとして記録する。単一リンクを全事件で強制せず、複数の根拠経路を認める。問いは何を比較するかを示し、答えの資料名を名指ししない。

## 心理実験

初期提示での反応を保存し、その後に条件・対照資料を開示する。再判断時にも最初の記録を上書きしない。提示条件の割当は固定して保存し、再読み込みで引き直さない。反応・判断の維持・変更に正誤や強弱スコアを付けない。一回の演出用ミニ実験は研究や個人診断ではなく、一般的効果・生涯能力を断定しない。

## 意思決定

目的、前提、資源、支持資料と反証を整理して方針を選ぶ。追加情報後に維持または更新できる。保留も方針の一つ。資料と整合する複数の方針を許容し、結果の幸不幸から判断を逆算して採点しない。未選択の結果は反実仮想として表示し、実際の結果と区別する。

## 報告と完了

主張・根拠・不確実性を構造化して提出する。自由文をAIで正誤判定しない。操作の未完了、事実誤認、根拠不足、未解消事項を分離して返す。計算2問・固定3断片・固定100点・残予算による優劣はV2では用いない。各方式の必要段階と根拠が揃うことが完了の条件で、判断や反応の値そのものを唯一解にしない。

例：広告の対象集団を誤って全利用者とした場合は資料上の事実誤認を指摘する。同じ事実を把握したうえで価格を重視して購入する、品質を重視して保留する、という選択の違いには一律の合否を付けない。実験で初回と同じ選択をした場合も比較段階を完了できる。

## 公平な高難易度

必要な情報は事件内に存在する。出典、適用範囲、欠落、矛盾、複数の根拠、制約を読むことで難しくする。単純三択だけ・文章量だけ・時間制限だけで難しくしない。ヒントは操作と問いを教え、根拠の答えを早期に公開しない。種明かしは明示操作で開く。
