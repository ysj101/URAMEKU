# 操作記録の既定送信への変更

ユーザーの指示により、同意カードを撤去し、送信先が設定された公開環境で既定送信へ変更する。
画面下に送信内容・Grafana Cloud・改善目的・30日の保持期間と設定へのリンクを常時表示する。
以前の拒否・停止を保持し、設定画面のスイッチで停止・再開できる。
SDKの内部opt-in設定は維持し、アプリ側だけで送信方針を変更する。内部キーのtrueを明示同意の記録として扱わない。

## 受入検証

- 初期状態でボタン操作なしにCASE00の開始が届き、CASE00とCASE01を最後まで解析できる。
- 画面上部に同意カードがなく、画面下の説明と設定リンクが表示される。320px・文字200%で横にはみ出さない。
- 保存済みの拒否・停止を引き継ぎ、再読み込みや他タブでも停止を維持する。
- 停止で送信待ちを破棄し、SDK読込中の停止・保存領域の例外・SDK失敗がゲームを妨げない。
- 自由入力・選択肢本文の非送信、対象外事件、保存復元も引き続き確認する。
- 全件削除はその場で停止し設定も消す。次回読み込みは既定送信に戻る。

## 文言の確認

専門知識のない人に向けた説明として読み比べ、yomiyasuのlint・差分・最終稿照合を実行。
「ます」の繰り返しは状態表示と短い説明のため維持した。資料との自動照合は未実施。
`yomiyasu-check: executed via=verify run=20261115T225816Z-22fed11f attempt=1 final=sha256:b81ccdca7cf0 mode=rewrite reader=general checks=lint,diff meaning_risk=0 replay=skipped`

この変更を、法令・契約上の同意不要の認定や素材の正式承認として扱わない。
