# 利用者テスト 観察者シート（1 セッション用）

印刷または別画面で開き、セッション中はここにメモする。終了後 15 分以内に `qa/user-tests/session-template.json` をコピーして `qa/user-tests/PNN.json` に転記する（フォーマットは `qa/user-tests/README.md`）。

**書いてよいこと**: 画面・操作・時刻・参加者の発言の引用・観察者が見た事実。
**書いてはいけないこと**: 参加者の性格・能力・理解の速さ・集中力・「○○バイアスにかかっている」などの評価。氏名・所属・年齢・性別。
