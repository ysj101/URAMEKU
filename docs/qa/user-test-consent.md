# 利用者テストへの参加について（同意文）

この文章は、テストを始める前に参加者に読んでもらい、口頭で同意を得るためのものです。**署名・氏名の記入は求めません。**

---

## テストの目的

これは、推理ゲーム「ウラメク」の試作版が**分かりやすく遊べるか**を調べるテストです。

調べるのはゲームの出来であって、あなたではありません。ゲームが難しかったり、途中で分からなくなったりしても、それはゲーム側の改善点です。

## これは心理テストではありません

- このテストは、あなたの考え方・性格・能力を判定するものではありません。そうした判定は行いませんし、記録もしません。
- ゲームに出てくる企業・人物・数字・出来事は、すべて**架空**のものです。

## 記録すること

観察者は、ゲームを改善するために次のことだけをメモします。

- どの画面で、どの操作に、何分ごろ時間がかかったか。
- 画面について話してくださったこと（引用として）。
- 終わったあとの質問への答え。
- 使った端末の種類（スマートフォン／PC など）。

## 記録しないこと

- 氏名・所属・連絡先・年齢・性別などの個人情報。記録では「参加者 P01」のような番号だけを使います。
- 画面の録画、写真、音声の録音。
- あなたの考え方や性格についての評価。

## あなたの権利

- いつでも、理由を言わずにやめられます。
- 答えたくない質問には答えなくてかまいません。
- 記録の内容を見たい場合は、観察者に言ってください。

## 所要時間

約 60 分です。

---

**観察者用**: 上記を読んでもらい、「参加してよいですか」と尋ねて口頭の同意を得てから開始する。同意の記録は `qa/user-tests/PNN.json` の `consent.verbal` を `true` にすることで行う（日時のみ。氏名は書かない）。
