# Release Gate — ゲート判定

| ゲート | 必須条件 | 現在 |
| --- | --- | --- |
| G0 納品物 | ZIP・マニフェスト・構造・実装タスクリスト・参照先が存在 | 自動検証予定 |
| G1 開発可能 | 5事件のJSON、ブラウザ試作、画像参照が整合 | 静的検査のみ |
| G2 MVP | UI完成・5事件E2E・保存・アクセシビリティ・実機確認 | 未達 |
| G3 デザイン | C-2原画と全人物ポーズの品質承認、全書類の読みやすさ | 未達 |
| G4 Web公開 | 商標調査・権利調査・利用規約・サーバ配信・障害対応 | 未達 |
