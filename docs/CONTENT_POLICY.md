# 事件コンテンツ制作・審査方針

- 5件はすべて架空の企業・登場人物・数字。実在のニュースを引用する場合は出典/日付/文脈をレビューする。
- 本文に「行動経済学の心理効果を体験する」と書く場合も、少数の選択で個人の特性を確定しない。
- 正解は資料の数値・母数・期間・母集団と一致すること。全分岐と数値を独立レビュー。
- 必要資料以外の閲覧で詰む場合には再挑戦・ヒント・保存の導線を提供。
- 自動生成コンテンツを審査無しで公開しない。
- 結果画面は「今回の状況での選択」を説明し、ユーザーの能力や人格を評価しない。

## 文言チェックリスト（MVP-017 で追加）

UI 文言・図鑑・実績・結果画面・ケース本文を追加/変更するときは以下を満たすこと。詳細な所見は `docs/reviews/fiction-and-concept-review.md`。

- 評価の主語は「記事」「証拠」「選択」であり、プレイヤー本人ではない。「あなたは○○タイプ」「〜な性格」「判断力が低い」「バイアスが強い」等の個人への断定を書かない。「診断」は「診断しません」という否定文以外で使わない。
- 学術概念の説明は「〜することがある」「〜しうる」「〜場合がある」等の確率的表現にする。「必ず」「誰でも」「常に」で一般化しない。学術的な出典名の記載は不要だが、誤った説明は書かない。
- 企業・店舗・商品・人物・メディア・調査会社は無名化（「靴店」「別の調査会社」等）し、実在名・酷似名を使わない。各ケースの `disclaimer` は必須で、UI でケース単位に表示する。
- 法的評価（不当表示・違法など）は断定しない。選択肢として出す場合は誤答側に置き、解説で「追加事実と法域の確認が必要」と補足する。

## 第三者名の扱い

- `AGENTS.md` のとおり、ユーザー向け仕様・ストア文言・`README.md`・`public/` に第三者の視覚的インスピレーション元（作品名・ブランド名・作者名・URL）を書かない。
- `docs/ART_BIBLE.md`・`docs/LEGAL_ASSET_REVIEW.md`・`design/` などの内部文書も、このリポジトリが公開されうる前提で同じ扱いとする。参照が必要な場合はリポジトリ外の非公開メモに置き、文書内では自社の正本（`design/reference/c2-canonical-board.png`）のみを指す。
- フォント名・ストア提出要件の URL など、権利処理や技術要件のための固有名は対象外。

## 機械チェック

- `npm run lint:content` で禁止・注意語（診断・性格・能力評価・実在企業名の簡易リスト等）を `data/**/*.json` と `src/**/*.tsx` に対して検出する。誤検知は `scripts/lint_content.mjs` の `ALLOW_PATTERNS` に文脈つきで追加する。
- 機械チェックは補助であり、人手レビュー（`docs/reviews/`）を置き換えない。
