# ケース番号と題材の対応

画面番号、JSONのID、素材パス、図鑑の解放先、攻略ガイドを同じ番号で管理する。一覧はID順に表示し、難易度を変えても番号を付け直さない。

| 画面・現行ID | 題材 | 保存形式v4までのID |
| --- | --- | --- |
| CASE 01 / case-01 | 平均おこづかい3000円 | case-06 |
| CASE 02 / case-02 | 教材で平均20点アップ | case-07 |
| CASE 03 / case-03 | 消えた55人の利用者 | case-01 |
| CASE 04 / case-04 | 半額セールの値札 | case-02 |
| CASE 05 / case-05 | 8割が支持の正体 | case-03 |
| CASE 06 / case-06 | 取り戻せない開発費 | case-04 |
| CASE 07 / case-07 | 急上昇するグラフ | case-05 |

保存形式v5への移行時に、選択中の事件、途中記録、完了状態、事件の改訂番号、旧MVPの履歴、改訂前の履歴を同時に移す。資料IDと回答は同じ題材に保持する。移行は一度だけ実行し、未来の保存形式は読み取り専用とする。

`archive/` と `src/test/fixtures/v1/` は旧版の記録として当時のIDを残す。V1互換テストの読み込み時だけ現行IDへ対応付け、資料の事実と正解は変更しない。
