# ウラメク — ゲームシステムV2仕様

この文書はゲームV2の現行仕様。旧計算中心MVPは `archive/game-v1/MVP_SPEC.md` に履歴として保存する。スターターであり、本番認証・アートの手動承認・実機検証の完了を意味しない。

## 体験と原則

架空の新聞社「調査編集局」で、資料から何が確認でき、何がまだ分からないかを整理する。**情報を読む → 仮説と根拠を組む → 実験または条件付き判断 → 追加情報で更新 → 振り返り**を事件ごとのJSONで構成する。

- 数値計算中心を廃止。数字は資料の事実として残すが、計算結果の入力を完了条件にしない。
- 情報解読・心理実験・意思決定シミュレーションを採用する。
- 矛盾する資料、出典、欠落、資源制約、トレードオフを読み解く高難易度を維持する。用語当て・単純三択・反射神経中心に戻さない。
- 判断そのものを安易に正誤判定しない。資料と矛盾する事実主張は検証し、目的に依存する方針・実験反応・結果の幸不幸とは分離する。

## 3つの方式

| 方式 | 入力と進行 | 完了・フィードバック |
| --- | --- | --- |
| 情報解読 | 出典・対象・期間・矛盾・欠落を読み、主張の解釈と根拠資料を記録する | 検証できる事実と根拠が揃ったかを確認。誤読は資料で説明し、未確認を虚偽と断定しない |
| 心理実験 | 初期条件で選択 → 条件・対照資料の提示 → 再判断 → 比較 | 両時点の反応を保存して比較。どちらの反応・判断維持でも進行し、個人特性を推測しない |
| 意思決定 | 目的・制約・前提・支持/反証を記録 → 方針選択 → 追加情報 → 更新 | 目的に沿う複数方針と保留を許容。根拠充足・手順と結果を分け、不運を誤答にしない |

全方式で、閲覧しただけでは根拠採用としない。資料間の補強・反証・条件・時系列を複数リンクで組み、主張と留保を記した構造化報告を提出する。自由文の人格診断やAI自動採点は行わない。

## 事件と難易度

| 事件 | V2の中心 |
| --- | --- |
| CASE 01 消えた55人の利用者 | 広告の対象範囲・分母・欠落を情報解読 |
| CASE 02 半額セールの値札 | 参照価格の提示と価格履歴の開示による判断比較 |
| CASE 03 8割が支持の正体 | 多数派表示と標本の開示、適用範囲の解読 |
| CASE 04 取り戻せない開発費 | 目的・将来条件に沿う継続／縮小／撤退／保留 |
| CASE 05 急上昇するグラフ | 軸・期間・比較対象を読み、掲載方針を更新 |

元資料の数値・分母・人物・企業は架空の事実として維持する。必要情報は事件内に存在し、資料の解読を要求する。予算、閲覧履歴、未読採用禁止、再読無料、再挑戦は継承する。行き詰まりはプレイヤーへの能力判定にせず、保留または再挑戦で回復できる。

## 評価・保存・UI

固定100点、計算2問必須、唯一の2資料照合、唯一の3断片順序をV2完了条件から外す。操作完了・事実整合・根拠充足・未解消事項を分けて表示する。根拠のない推測だけでは完了しないが、価値判断を唯一の正解に合わせる必要はない。

事件はJSON正本、静的Web、端末内保存。ゲームV2と保存形式の版は別概念。旧完了をV2完了に読み替えず、初回判断・提示条件・更新を再開できる。削除は関連する端末内データすべてを対象とする。外部分析送信・認証・AI事件生成は追加しない。

タップ・キーボード、320〜430px、文字200%、44px相当の対象、色以外の状態表示、Reduced Motionを維持する。製品名ウラメク、C-2正本シルエットを維持し、顔を生成し直さない。未審査素材を承認済みにしない。
