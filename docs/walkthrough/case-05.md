## 推奨調査順と主経路

1. 無料`graphic`を読み、掲載・追加確認・保留などの初回方針を目的と前提付きで残す。`questions`は初回後に開示される。

3. 解読は`observed_change`、`axis_range`、`causality_unresolved`。回答記録の変化・見た目の強調・因果の未確認を区別する。
4. `raw → graphic: supports`、`axis → graphic: qualifies`、`questions → raw: qualifies`を組む。
5. 調査条件を読んだ後の掲載方針と理由を記録し、確認済みの変化と未確認の原因を分けて報告する。

## 別経路と複数の編集方針

関係の別経路は`graphic → axis: supports`、`axis → raw: qualifies`、`questions → raw: qualifies`。表示と制作指示の対応から元データの読み取りへ戻る。対象限定で早く伝える、調査方法を追加確認する、掲載を保留するという方針は、それぞれ速さ・比較可能性・誤解の抑制の優先順位を説明すれば進行できる。更新後の方針は初回と同じでよい。
