## 推奨調査順と主経路

1. 最初の提示で購入・比較・見送り・保留のいずれかを記録する。どの反応でも進める。価格履歴と実売記録は初回判断後に開く。
2. 無料`poster`、`launch`、`history`、`stock`を開いて採用する。消費3、残り1。直近価格との差は資料にあり、計算し直さない。
3. 解読は`launch_comparison`、`observed_sales`、`value_is_conditional`。根拠を添える。
4. `poster → history: qualifies`、`history → stock: supports`で比較基準と実売の裏付けを組む。
5. 履歴を踏まえた再判断と理由を記録し、確認した事実と購入者の条件を区別して報告する。

## 別経路と別判断

`launch`の代わりに`interview`を調べ、`interview_comparison`と`interview → history: qualifies`を使っても消費3で成立する。担当者の説明だけで済ませず独立した履歴・実売を併用する。購入・比較・見送り・保留のどれを初回・更新後に選んでも、それ自体は採点しない。

## 未確認事項・回復

類似商品は同一商品ではなく、最安の直接証拠にはならない。価格差から法的評価や購入者全員の損得を断定しない。必要経路は3、追加取材1件の余地。予算切れなら再挑戦する。実験の提示条件は再読・再起動・再挑戦で引き直さない。
