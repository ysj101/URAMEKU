# ウラメク｜本番化・公開タスク
- 対象：公開Web/PWAを基本線とし、アプリストア配信は追加判断。
- 判定：「素材が存在する」≠「本番品質が承認された」。配布前に実機・権利・科学的な表現をレビュー。
- 公開ゲート：P0 の全項目をレビュー承認。P1 は本番後改善としてもよいが、未完了の影響を明記。
- **ストア用スクリーンショットだけは完成したアプリ実画面から採取する必要があり、現時点で最終版は制作できない。**

タスク総数 **46件**。工数の積算 **547時間**（個人開発の初期概算であり、納期の約束ではありません）。
> チェック欄は **着手済みを意味しません**。成果物の存在と動作検証は別管理です。
