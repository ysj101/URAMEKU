# ウラメク｜MVP実装タスク
- 対象：スマホ優先の静的Web/PWA。React + TypeScript + Viteへの段階移行を想定。
- コアメカニクス：資料調査 → 2資料照合 → 数値検証2件 → 根拠付き記事作成 → 採点・種明かし。
- 完了定義：5事件を実ブラウザで遊べて、保存・入力・アクセシビリティが検証済みであること。
- 優先順位：P0 はMVPリリース前に必須。推理の難易度を単純な選択式へ戻さない。

タスク総数 **45件**。工数の積算 **418時間**（個人開発の初期概算であり、納期の約束ではありません）。
> チェック欄は **着手済みを意味しません**。成果物の存在と動作検証は別管理です。

## 基盤（P0）

- [ ] **MVP-001｜リポジトリ初期化、lint/format/typecheck設定**（目安 8h）  
  受け入れ条件：`npm ci`、`npm run lint`、`npm run typecheck` が再現可能。
- [ ] **MVP-002｜Vite + React + TypeScriptの本実装環境**（目安 10h）  
  受け入れ条件：開発/productionビルドと静的デプロイが成功。

  受け入れ条件：判定関数がDOM参照なしで単体テスト可能。
- [ ] **MVP-004｜公開URLとベースパスを決め、assets参照統一**（目安 5h）
